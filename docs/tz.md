# Техническое задание: Bitrix24.Desktop

Настольный клиент чата Битрикс24 для одного портала. Программа показывает список личных и групповых диалогов, переписку, вложения, реакции, всплывающие уведомления и изменения задач, где текущий пользователь ответственный.

Платформа: Windows, .NET 8, WPF, WebView2 для входа, SQLite для кэша. Шрифт окна — Segoe UI, 14 px, если у элемента не указан другой размер. Секрет локального приложения в задание не входит. Снимки в `docs/mockup` сняты с опубликованного `Bitrix24.Desktop.exe` 3 ноября 2026 года, окно 1112×640. Имена, тексты и ссылки на них — эталон внешнего вида, а не обязательные данные.

Читать по одной части. В каждом файле правила этой зоны собраны один раз. Ещё не сделанное — в [доработках](dorabotki.md), это не описание текущей программы.
