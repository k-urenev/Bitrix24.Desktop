# Опрос и REST

Часть [технического задания](../tz.md). Интервалы, карточки за проход, задачи, методы. Вид карточки, звуки и срок жизни — в [оболочке](obolochka.md).

Фон опрашивает портал. Если подошли оба срока, сначала идут чаты.

| Что | Интервал |
| --- | --- |
| Чаты, `im.recent.list` | сразу по сигналу Push&Pull (`pull.config.get`, WebSocket или длинный опрос); без сигнала — каждые 15 секунд |
| Задачи, `tasks.task.list` | 60 секунд; четыре запроса — постановщик, исполнитель, соисполнитель, наблюдатель; вместе не больше 200 задач |
| Нет прав на задачи | следующий опрос задач через 10 минут |
| Нет Push&Pull | при открытии сохранённый вход заново получает токен, затем `scope`. Нет `pull`, либо три неудачных восстановления канала: шапка «На связи. Нет мгновенных сообщений», чаты раз в 15 секунд |
| Сравнение задач | окно захватывает лишние 10 минут, чтобы не пропустить правку на границе |

Сервер версии 4 отдаёт кадры protobuf, как веб-мессенджер портала: в адресе канала `binaryMode=true`, имя хоста и `revision`. Команда сообщения из кадра сразу запрашивает список чатов.

Сигнал `startWriting` список чатов не обновляет: он показывает строку «печатает» в открытом диалоге.

В строку журнала о новом последнем сообщении попадает состояние окна, запомненное при последней смене окна: на экране, свёрнуто или скрыто. Опрос это состояние у окна не спрашивает.

Опрос открытого диалога просит обновить ленту. Пока главное окно активно, по этому диалогу карточка не ставится и играет звук открытого чата. Сообщение из другого чата при активном окне играет звук нового сообщения без карточки. Это сообщение открытого диалога не занимает место в тройке карточек за проход. «Не беспокоить» глушит карточки и звук. За проход не больше трёх карточек сообщений из других диалогов и трёх карточек задач. Первый успешный опрос чатов и первый успешный опрос задач только запоминают точку отсчёта.

Карточка сообщения не ставится на своё сообщение и на системное. Для них и для «Не беспокоить» курсор уведомления сдвигается сразу, звука нет. Курсор открытого диалога тоже сдвигается сразу. Если новых диалогов, кроме открытого, больше трёх, лишние в этот проход не помечаются.

Сетевая ошибка оставляет «Нет связи с порталом» и повторяет тот же опрос по обычному интервалу. Ограничение частоты отрабатывается внутри клиента, до пяти попыток. Если портал так и не ответил, оба опроса ждут паузу, которую посчитал клиент, иначе 30 секунд. В шапке «Портал ограничил запросы, ждём».

Задача даёт карточку, если с прошлого снимка изменились статус, крайний срок, ответственный или число комментариев. В опрос попадают задачи, где пользователь постановщик, исполнитель, соисполнитель или наблюдатель. Задача «без звука» карточку не даёт и на страницу «Уведомления» не пишется, но снимок обновляется, поэтому после включения звука старая правка уже не всплывает. Новая для снимка задача с датой создания не раньше прошлого опроса пишется как «Вам назначена задача», если пользователь исполнитель; «Вы поставили задачу», если он постановщик; «Вы соисполнитель» или «Вы наблюдатель» — для этих ролей. Более старая — как «Задача обновлена». Текст изменений: «Статус: … → …», «Крайний срок: … → …», «Изменился ответственный», «Оставлен комментарий». Не показанные задачи в снимок не записываются. «Не беспокоить» глушит карточки и записывает весь новый снимок, поэтому после снятия режима старые правки уже не всплывают.

Страница «Уведомления» показывает те же карточки задач. Новая запись непрочитанная, встаёт сверху и остаётся после перезапуска. Если в правке есть новый комментарий и эта задача уже есть в ленте, строка не добавляется: у существующей записи меняются текст, время и пометка непрочитанного. Пока страница открыта, записи этого пользователя помечаются прочитанными. Хранится не больше 200 записей этого пользователя. Выход из аккаунта ленту на экране убирает; после входа тем же пользователем записи снова на месте, непрочитанные по-прежнему непрочитанные, если страницу не открывали.

## REST

Вызовы идут с OAuth-токеном. Методы:

| Метод | Зачем |
| --- | --- |
| `user.current` | Имя и id текущего пользователя |
| `scope` | Права токена при открытии. Нет `pull` — канал Push&Pull не поднимается |
| `im.recent.list` | Список диалогов и статус последнего сообщения |
| `im.dialog.messages.get` | Лента |
| `im.dialog.get` | `readed_list` |
| `im.message.add` | Текст |
| `im.v2.File.upload` | Файл до 20 МБ, base64 |
| `im.dialog.read` | Свой курсор прочтения |
| `disk.file.get` | Скачивание вложения |
| `tasks.task.list` | Задачи пользователя |
