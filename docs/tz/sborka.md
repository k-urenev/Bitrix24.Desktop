# Сборка и приёмка

Часть [технического задания](../tz.md).

Среда .NET и WPF лежит рядом с exe отдельными файлами. Exe их не пакует. Повторная публикация не переписывает эти файлы, если они не менялись. Картинки смайлов, знаки реакций и звуки по-прежнему рядом: `Assets\emoji`, `Assets\reactions`, `Assets\sounds`. Рядом же нужны `chat-wash.png` и `chat-pattern.png`, если они не вшиты в сборку.

Из корня репозитория:

```powershell
dotnet test Bitrix24.Desktop.sln -c Release
```

Публикация. Сначала уже запущенный экземпляр закрывается через `--exit`: значок уходит из трея. Если процесс не вышел, его останавливают принудительно: каталог совпадает с запущенным exe.

```powershell
$env:Path = "$env:LOCALAPPDATA\Microsoft\dotnet;" + $env:Path
$exe = "$env:USERPROFILE\Desktop\Bitrix24\Bitrix24.Desktop.exe"
if ((Test-Path $exe) -and (Get-Process -Name Bitrix24.Desktop -ErrorAction SilentlyContinue)) {
    & $exe --exit
    $deadline = (Get-Date).AddSeconds(8)
    while ((Get-Process -Name Bitrix24.Desktop -ErrorAction SilentlyContinue) -and (Get-Date) -lt $deadline) {
        Start-Sleep -Milliseconds 200
    }
}
Stop-Process -Name Bitrix24.Desktop -Force -ErrorAction SilentlyContinue
Start-Sleep -Seconds 1
dotnet publish src\Bitrix24.Desktop\Bitrix24.Desktop.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=false -p:DebugType=none -p:DebugSymbols=false -o "$env:USERPROFILE\Desktop\Bitrix24"
Remove-Item "$env:USERPROFILE\Desktop\Bitrix24\*.xml" -ErrorAction SilentlyContinue
```

Установщик для коллеги — `Bitrix24-Setup-1.0.4.exe` на рабочем столе. В имени файла всегда стоит версия программы. Его собирает Inno Setup из только что опубликованной папки:

```powershell
$iscc = @(
    "${env:ProgramFiles(x86)}\Inno Setup 6\ISCC.exe",
    "$env:LOCALAPPDATA\Programs\Inno Setup 6\ISCC.exe"
) | Where-Object { Test-Path $_ } | Select-Object -First 1
& $iscc "/DPublishDir=$env:USERPROFILE\Desktop\Bitrix24" "/O$env:USERPROFILE\Desktop" installer\Bitrix24.iss
Copy-Item "$env:USERPROFILE\Desktop\Bitrix24-Setup-1.0.4.exe" "release\Bitrix24-Setup-1.0.4.exe" -Force
```

В свойствах exe и установщика описание и организация — «Неофициальная сборка Битрикс24 Мессенджера». Та же строка стоит на странице «О программе» под названием. Публичный репозиторий содержит исходники и `release\Bitrix24-Setup-1.0.4.exe`. Адреса портала, кода, секрета, логина и пароля в нём нет.

Мастер спрашивает, ставить программу для всех или только для текущего пользователя, и путь. Для всех путь по умолчанию — `C:\Program Files\Bitrix24`, для одного пользователя — `%LOCALAPPDATA%\Programs\Bitrix24`. В выбранную папку кладутся exe, файлы среды .NET и WPF рядом с ним и папки `Assets\emoji`, `Assets\sounds`, `Assets\reactions`, вместе с `Assets\app.ico`. Ярлыки «Битрикс24» появляются в меню «Пуск» и на рабочем столе. Значок ярлыка — `Assets\app.ico`. Адрес портала, код, секрет, логин и пароль установщик не записывает: их вводят при первом входе. На последней странице можно сразу запустить программу. Если она уже запущена, мастер просит закрыть её. Повторный запуск того же установщика пишет файлы поверх уже установленной копии в её папке и не удаляет её заранее. Каталог данных не трогает. Удаление из списка приложений Windows убирает папку установки и оба ярлыка. Каталог данных в `%LOCALAPPDATA%\Bitrix24.Desktop` удаление не трогает.

## Приёмка

Собранная заново программа совпадает с этим заданием, если:

1. Один экземпляр, крестик прячет окно в трей, «Выход» завершает процесс.
2. Портала по умолчанию нет. Адрес, код и секрет вводит пользователь. Инструкция, где их взять, свёрнута в «Где взять код и секретный ключ». Эти настройки сохраняются. Логин и пароль тоже вводятся и сохраняются. Протухшая сессия возвращает на вход. Если IP-адрес портала не находится, форма пишет об этом и окно браузера не открывает.
3. Окно 1112×640, рейка 72 px, список 400 px, цвета и тексты как на снимках и в таблицах задания.
4. В списке только личные и групповые диалоги, поиск местный, выбранная строка бирюзовая.
5. Свои пузыри справа и зелёные, чужие слева и белые, системные по центру, плашка дня липнет.
6. По умолчанию Enter переносит строку, Ctrl+Enter отправляет. Радио «Отправлять Enter, Перенос Ctrl+Enter» меняет их местами. Shift+Enter переносит в обоих пунктах. Ctrl+R обновляет ленту выбранного чата и закешированные аватары, файл больше 20 МБ отклоняется.
7. Одна серая галочка — отправлено, две синие — прочитано другим участником.
8. Новое сообщение в мессенджере запрашивает список чатов сразу через Push&Pull. Если канала нет, чаты опрашиваются раз в 15 секунд. Задачи — раз в 60. Карточек за проход не больше трёх каждого вида, сообщение открытого диалога в этот предел не входит. На экране не больше трёх, новая над предыдущей, четвёртая убирает самую раннюю. Карточка живёт 15 секунд и один раз продлевается ещё на 15, если указатель за первые 15 секунд не сдвинулся. При неактивном окне чужое сообщение играет звук нового сообщения и показывает карточку. При активном окне карточки нет: выбранный чат играет звук открытого чата, другой чат — звук нового сообщения. Задача играет звук задачи, своя отправка — звук отправки. Пока свой файл не выбран, это `new-message-1.mp3`, `new-message-2.mp3`, `reminder.mp3` и `send.mp3`. Крестик без рамки только закрывает карточку, тени нет, обводка одинаковая по контуру.
9. «Не беспокоить» глушит карточки. Страница «Уведомления» показывает изменения задач, где пользователь постановщик, исполнитель, соисполнитель или наблюдатель. Задача «без звука» туда не попадает. В «Настройках» два чекбокса, два радио, четыре поля звука и внизу справа `1.0.4` шрифтом 8 px. «Запускать с компьютером» пишет текущий exe в автозагрузку пользователя Windows. «Запускаться свернутым (появляться только в трее)» при живой сессии оставляет первый запуск в трее. Радио выбирает, какая клавиша отправляет сообщение. На странице «О программе» под названием стоит «Неофициальная сборка Битрикс24 Мессенджера». Ссылка «Архив для техподдержки» сохраняет zip без файла сессии.
10. После перезапуска видны последние диалоги и до 400 сообщений на диалог из SQLite, сессия читается только тем же пользователем Windows.
