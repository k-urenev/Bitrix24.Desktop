# Данные

Часть [технического задания](../tz.md). Каталог, сессия, таблицы, чистка текста и цитаты.

Каталог `%LocalAppData%\Bitrix24.Desktop`.

| Файл | Содержимое |
| --- | --- |
| `auth.bin` | Сессия, DPAPI текущего пользователя Windows |
| `app.db` | SQLite, журнал WAL |
| `app.log` | Журнал ошибок, окна и догрузки ленты |
| `WebView2` | Профиль браузера входа |
| `link-previews` | Картинки карточек ссылок |

`auth.bin` читается только тем пользователем Windows, который его записал. В нём домен, код, секрет, логин, пароль, токены, срок access-токена, адреса REST и обмена, `member_id`, id и имя, флаг «Не беспокоить», флаг «Запускаться свернутым», флаг «Отправлять Enter», четыре пути звуков: новое сообщение, открытый чат, отправка, задача. Выход из аккаунта стирает токены и оставляет флаги и пути. Пустой флаг «Отправлять Enter» значит прежнюю раскладку: Ctrl+Enter отправляет, Enter переносит. Пустой путь звука значит стандартный файл из `Assets/sounds`.

В журнал пишутся смена окна (на экране, свёрнуто, скрыто в трей), новое последнее сообщение в списке чатов, просят ли догрузить ленту выбранного чата, сколько сообщений отдал портал и есть ли id из превью в ленте.

Ссылка «Архив для техподдержки» на странице «О программе» собирает zip: `info.txt`, `app.log`, снимок `app.db` и `gaps.txt` с чатами, где последнее сообщение списка новее хвоста ленты. Первая строка `info.txt` — «версия» и тот номер, который виден на этой странице. Сессия `auth.bin` в архив не входит.

`app.db` при выходе не очищается и не делится по пользователям портала. После смены аккаунта на том же пользователе Windows до следующего опроса видны прежние диалоги, кэш и снимки задач. Базовая точка уведомлений тоже общая. Это текущее ограничение, его нужно сохранить, если цель — повторить программу, а не исправить.

## Таблицы

- `dialogs` — строка списка: заголовок, превью, id и автор последнего сообщения, время, непрочитанные, тип, порядок, `last_delivered`, курсор `others_read_message_id`, id чата.
- `reaction_marks` — непрочитанная реакция: диалог, id чата и id сообщения. Строка есть, пока этот диалог не открыт.
- `messages` — лента. Вложения в `files_json`. Ключ — пара диалога и id сообщения. На диалог хранятся последние 400 сообщений.
- `dialog_cursors` — id последнего сообщения, о котором уже уведомляли, и id, до которого диалог помечен прочитанным локально.
- `task_snapshots` — последний снимок задач.
- `app_flags` — `messages_baseline`, `tasks_baseline`, `tasks_polled_at`.
- `task_notices` — лента страницы «Уведомления»: задача, заголовок, текст, ссылка, время и флаг непрочитанного. На пользователя хранятся последние 200 записей. Записи, которые уже лежали в базе до появления флага, остаются прочитанными.
- `link_previews` — карточка первой ссылки у сообщения, отправленного из этой программы: адрес, заголовок, описание и путь к картинке. Ключ — пара диалога и id сообщения. При удалении старых сообщений из `messages` карточка остаётся.

## Текст

Текст портала перед показом нормализуется. `[USER=…]…[/USER]` превращается в ссылку `https://[домен]/company/personal/user/[id]/` с подписью-именем. В ленте теги `b`, `i`, `u`, `s` сохраняются и рисуются полужирным, курсивом, подчёркиванием и зачёркиванием; в превью диалога и уведомлении эти теги снимаются, имя из `[USER]` остаётся текстом. Теги `br`, `img`, `size`, `color`, `quote`, `font`, `p` снимаются. Блок `[code]…[/code]` в ленте остаётся и рисуется моноширинным на серой плашке; в превью диалога и уведомлении теги снимаются, текст кода остаётся в строке. `[URL]` в ленте остаётся для кликабельной ссылки, в однострочном превью показывается подпись. В строке списка повторные пробелы схлопываются.

Цитата — блок между линиями из дефисов или знаков равенства длиной от 20 символов, с необязательной шапкой «имя [время]». В пузыре это отдельная плашка. В превью и уведомлении цитата пишется «[Цитата]». Слова до неё и после неё остаются.
